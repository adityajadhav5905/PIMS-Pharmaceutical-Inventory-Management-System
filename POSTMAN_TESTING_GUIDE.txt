1. QUICK START
================================================================================

Step 1: Download & Import Collection
  1. Open Postman (Download from https://www.postman.com/downloads/)
  2. Click "Import" in the top-left corner
  3. Select "Upload Files"
  4. Choose POSTMAN_COLLECTION.json from this project root
  5. Click "Import"

Step 2: Setup Environment Variables
  1. The collection includes default variables:
     - base_url: http://localhost:5000
     - authToken: (auto-filled after login)
     - refreshToken: (auto-filled after login)
     - inventory_id, transaction_id, alert_id, staff_id
  
  2. To use custom values:
     - Click the environment dropdown in Postman
     - Select or create an environment
     - Update the values as needed

Step 3: Start Your Server
  ```bash
  cd server
  npm run dev
  ```

Step 4: Run API Tests
  1. Navigate to "Authentication" folder
  2. Run "Login User" first to get auth token
  3. Token is automatically saved to authToken variable
  4. Use other endpoints with the saved token

2. AUTHENTICATION FLOW
================================================================================

All endpoints (except Login/Register) require authentication via Bearer token.

Step 1: Register New User (Optional)
  Endpoint: POST /api/v1/auth/register
  Body:
  {
    "name": "John Pharmacist",
    "email": "john@hospital.com",
    "password": "SecurePass123!"
  }
  
  Response:
  {
    "user": { ... },
    "token": "eyJhbGc...",
    "refreshToken": "eyJhbGc..."
  }

Step 2: Login
  Endpoint: POST /api/v1/auth/login
  Body:
  {
    "email": "admin@hospital.com",
    "password": "ChangeMe123!"
  }
  
  Response Includes:
  - token (JWT, expires soon)
  - refreshToken (long-lived)
  
  ✓ Token is auto-saved to {{authToken}} variable
  ✓ RefreshToken is auto-saved to {{refreshToken}} variable

Step 3: Use Token in Requests
  All authenticated requests include:
  Header: Authorization: Bearer {{authToken}}
  
  This is already configured in all collection requests!

Step 4: Refresh Token (When Needed)
  Endpoint: POST /api/v1/auth/refresh
  Body:
  {
    "refreshToken": "{{refreshToken}}"
  }
  
  Returns new token when current one expires

Step 5: Get Your Profile
  Endpoint: GET /api/v1/auth/profile
  Headers: Authorization: Bearer {{authToken}}
  
  Response: Your user profile data

Step 6: Update Profile
  Endpoint: PUT /api/v1/auth/profile
  Headers: Authorization: Bearer {{authToken}}
  Body:
  {
    "name": "New Name",
    "email": "newemail@hospital.com"
  }

5. TRANSACTIONS ENDPOINTS
================================================================================

Track stock movements (IN/OUT operations).

─────────────────────────────────────────────────────────────────────────────
5.1 List All Transactions
─────────────────────────────────────────────────────────────────────────────

Endpoint: GET /api/v1/inventory/transactions
Authorization: Bearer {{authToken}}

Returns all stock transactions (purchases and sales).

─────────────────────────────────────────────────────────────────────────────
5.2 Create Stock Transaction
─────────────────────────────────────────────────────────────────────────────

Endpoint: POST /api/v1/inventory/transactions
Authorization: Bearer {{authToken}}
Role Required: Admin, Pharmacist

Request Body (IN - Purchase):
{
  "medicine": "507f1f77bcf86cd799439012",
  "inventory": "507f1f77bcf86cd799439013",
  "quantity": 30,
  "type": "IN",
  "unitBuyPrice": 2.5,
  "unitSellPrice": 5,
  "note": "Stock replenishment"
}

Request Body (OUT - Sale):
{
  "medicine": "507f1f77bcf86cd799439012",
  "inventory": "507f1f77bcf86cd799439013",
  "quantity": 10,
  "type": "OUT",
  "unitBuyPrice": 2.5,
  "unitSellPrice": 5,
  "note": "Ward issue"
}

Response Includes:
- totalCost: quantity × unitBuyPrice
- totalRevenue: quantity × unitSellPrice (only for OUT)
- profit: totalRevenue - totalCost (only for OUT)

─────────────────────────────────────────────────────────────────────────────
5.3 Sell Stock (Simplified)
─────────────────────────────────────────────────────────────────────────────

Endpoint: POST /api/v1/inventory/sell
Authorization: Bearer {{authToken}}
Role Required: Admin, Pharmacist

Request Body:
{
  "medicine": "507f1f77bcf86cd799439012",
  "inventory": "507f1f77bcf86cd799439013",
  "quantity": 5,
  "note": "Ward issue"
}

Note: Prices and profit are calculated automatically from medicine and inventory data.

─────────────────────────────────────────────────────────────────────────────
5.4 Update Transaction

13. COMMON ISSUES & SOLUTIONS
================================================================================

Issue: "401 Unauthorized" Error
Solution:
  1. Run "Login User" endpoint first
  2. Check token is saved in authToken variable
  3. Verify Authorization header exists: Bearer {{authToken}}
  4. Token might have expired, refresh it

Issue: "403 Forbidden" Error
Solution:
  1. You don't have required role (Admin/Pharmacist)
  2. Check your user role in database
  3. Login as admin: admin@hospital.com / ChangeMe123!

Issue: "404 Not Found" Error
Solution:
  1. Endpoint path might be wrong
  2. Resource ID ({{inventory_id}}) might not exist
  3. Copy actual IDs from list endpoints
  4. Update variables with correct IDs

Issue: "400 Bad Request" Error
Solution:
  1. Request body format is incorrect
  2. Required fields missing
  3. Check body syntax in Postman
  4. Compare with examples in this guide

Issue: "Connection Refused" Error
Solution:
  1. Server is not running: npm run dev
  2. Wrong base_url variable
  3. Check port 5000 is not blocked
  4. Verify server started successfully

Issue: Token Not Auto-Saving
Solution:
  1. Check "Login User" response includes "token"
  2. Verify test script is enabled in request
  3. Manually copy token to {{authToken}} if needed
  4. Check Postman environment is active
